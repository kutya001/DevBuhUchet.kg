#### Справочники платформы Buhuchet.kg (исчерпывающие)

Полное содержимое справочников, которые ведёт только администратор платформы. Файл — источник для `refDB.json` прототипа: каждый раздел ниже — один ключ JSON, каждое значение — одна запись, поля записи перечислены в строке «Поля» раздела с ключом JSON в скобках. Налоговые данные сверены с Налоговым кодексом КР от 18.01.2022 № 3 в редакции Закона от 06.08.2026 № 145 (файл кодекса прислал заказчик). Коды форм STI, коды платежей (КБК) и коды УГНС кодекс не задаёт: где их не удалось подтвердить, стоит «сверить с ГНС». Ставки, которые устанавливает Кабинет министров или другие законы (Соцфонд, ПВТ, СЭЗ, местные кенеши), помечены отдельно. Всё, что дописано без заказчика, помечено **(по умолчанию)**.

##### Как читать файл

- **Ключ раздела** — имя массива в `refDB.json` (например, `regimes`); в прототипе v30 он уже есть в объекте `DICT`, новые ключи помечены «новый»
- **Код записи** — постоянный код значения (например, `РЕЖ-01`); по нему записи сопоставляются при загрузке из Excel, переименование не создаёт дубль
- **Активен** — `active: true`, если не сказано «отключено»; отключённые записи остаются в файле, чтобы старые данные не потеряли ссылку
- **Ссылки между справочниками** — по коду или `id` (например, у вида отчёта `regimes: ['ОНР']`, у налога `reportTypes: ['nds']`)
- **Даты** — `ГГГГ-ММ-ДД`; суммы — в сомах; проценты — строкой с пробелом перед «%» («12 %»), как в прототипе

	- Виды отчётов при назначении контрагенту предлагаются с учётом ГКЭД: роялти и бонус — при секции `B`, акциз — при `11.01`–`11.05`, `12.00`, `19.20`; ничего не назначается автоматически
	- При смене ГКЭД — предупреждение, какие режимы, ставки и льготы перестали подходить; уже созданные отчёты не меняются

##### Чего в справочниках пока не хватает

- Коды форм STI у видов gdn, min, gam, gamo, imi, socip и подтверждение остальных кодов — сверить с ГНС
- Коды бюджетной классификации (КБК) по каждому платежу — сверить с ГНС и Минфином
- Коды УГНС (кодекс их не содержит) и точный состав управлений — сверить с ГНС
- Ставки страховых взносов и фиксированные взносы ИП — по закону о тарифах страховых взносов, сверить с Соцфондом
- Размер и сроки отчислений резидентов ПВТ, ПКИ и плата субъектов СЭЗ — по своим законам, в НК их нет
- Перечни Кабинета министров: базовые суммы патента по видам деятельности, ставки в зоне торговли за торговое место, приграничные населённые пункты, территории ст. 183, ставка бонуса
- Реестр банков — сверить с реестром лицензий Нацбанка
- Даты Орозо айт и Курман айт, переносы выходных на 2027 год
- Освобождения по подоходному налогу (гл. 23) и по НДС (гл. 38) не разложены в отдельные справочники: это свойства доходов и поставок, а не контрагента
- Коды ГКЭД для перечней Кабинета министров и отдельных законов: виды деятельности на патенте, ПВТ, СЭЗ, СФИТ «Тамчы» (у ПКИ остались только коды позиций 6 и 8 и номер редакции постановления); коды для майнинга, казино и букмекеров, виртуальных активов (в ГКЭД 2022 их нет) — сверить с ГНС, дирекциями ПВТ и ПКИ, Нацстаткомом
