### Этап 0. Фундамент (25.10.2026)

- Отдельный репозиторий продукта.
	- Сайт (Next.js), API (Hono), бизнес-правила без базы, база (PostgreSQL, Drizzle, защита данных организаций на уровне строк), переходники к хранилищу, расписанию и Telegram, общие компоненты.
- Проверки на каждый PR и автослияние.
	- Проверяются типы, линтер, переносимость («своя мебель»), карта приёмки, тесты и сквозные тесты в Docker.
	- Описание PR должно содержать отчёт двух ревьюеров: соответствие ТЗ и безопасность.
- Тестовый стенд test.buhuchet.kg работает с 25.10. Он стоит на Vercel и Supabase Free (Ирландия). Миграции на стенд запускает только GitHub Actions.
- Наполнение: справочники из refDB, ГКЭД, демо-организация.
