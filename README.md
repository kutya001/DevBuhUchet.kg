# Buhuchet.kg — кликабельный прототип

Прототип системы автоматизации бухгалтерского аутсорсинга: учёт сдачи налоговых отчётов по контрагентам, задачи, поступления и оплата налогов, справочники платформы.

- Файл прототипа: [`index.html`](index.html) — самодостаточная HTML-страница, открывается в браузере без сборки.
- Текущая версия: **v31** от 18.10.2026 — прототип стал каркасом без данных: данные вынесены в три JSON-файла в папке `data/`, в `index.html` встроена их копия.

- Техническое задание: [`docs/ТЗ Buhuchet.kg.md`](docs/ТЗ%20Buhuchet.kg.md) (итоговое).
- Справочники платформы: [`docs/Справочники платформы (исчерпывающие).md`](docs/Справочники%20платформы%20%28исчерпывающие%29.md) — источник, из которого собран `data/refDB.json`.
- Инструкция по системе: [`docs/Инструкция Buhuchet.kg.md`](docs/Инструкция%20Buhuchet.kg.md).

## Данные

На GitHub Pages прототип читает данные из папки `data/` рядом с `index.html`:

- `data/demoDB.json` — демо-данные для показа прототипа;
- `data/TemDB.json` — пустой шаблон для рабочих данных организации;
- `data/refDB.json` — справочники платформы.

Копия этих файлов встроена в `index.html`, поэтому страница открывается и с диска. После правки JSON встроенную копию пересобирает `data/build.py`: `python3 data/build.py index.html data`.

Каждая новая версия прототипа заменяет `index.html` и при необходимости файлы в `data/`, номер версии и дата обновляются здесь.
