# Buhuchet.kg — кликабельный прототип

Прототип системы автоматизации бухгалтерского аутсорсинга: учёт сдачи налоговых отчётов по контрагентам, задачи, поступления и оплата налогов, справочники платформы.

## Как это устроено

- Без npm, сборщиков и фреймворков. Файлы из `src` подключаются обычными тегами `<link>` и `<script>` в `index.html`.
- Все скрипты работают в одной общей области видимости: функции и константы, объявленные в одном файле, видны в остальных.
- **Порядок подключения важен.** Во время загрузки файл может вызывать только то, что объявлено в файлах выше. Внутри функций (которые вызываются позже, по клику) можно обращаться к чему угодно. `core/registry.js` ссылается на функции отрисовки всех модулей, поэтому подключается после них, а `start.js` — последним.
- Каждый файл начинается с `'use strict';` и строки-комментария о содержимом.

## Куда вносить правки

- Модуль или вкладка — файл модуля в `src/js/modules/` или `src/js/admin/`.
- Название, иконка, вкладки, описание модуля — `src/js/core/registry.js`.
- Столбцы по умолчанию и поведение всех списков — `src/js/ui/grid.js`.
- Статусы и их шкалы — `src/js/ui/status-scale.js`, состав и названия — `data/refDB.json`.
- Внешний вид — нужный файл в `src/css/`.
- Данные — JSON в `data/` (источник правды; встроенная копия в собранном файле делается сборкой).
- Новый файл — положить в нужную папку `src` и добавить тег в `index.html` в правильное место по порядку.
- Новая версия — поднять `PROTO_VER` в `src/js/ui/shell.js` и `<title>` в `index.html`, добавить запись в `news` в `data/refDB.json`.

## Сборка однофайловой версии

```
python3 build.py                  # → dist/prototype.html
python3 build.py "Прототип Buhuchet.kg v32.html"
```

Нужен только Python 3. Скрипт объединяет все стили в один `<style>`, все скрипты в один `<script>` в порядке из `index.html` и встраивает копию JSON из `data/` и библиотеку `vendor/pdfjs` (блоками `type="text/plain"`: pdf.js запускается только при первой загрузке PDF, поэтому «Из свидетельства и выписки» работает с диска и в артефакте без сети). Собранный файл публикуется в артефакт claude.ai и открывается с диска. После любой правки в `src` или `data` пересоберите его перед коммитом.

## Локальный запуск

Многофайловая версия читает `data/` по сети, поэтому с диска (`file://`) её не открыть — нужен веб-сервер:

```
python3 -m http.server 8000      # затем http://localhost:8000/
```

С диска открывайте `dist/prototype.html`.

## Данные

- `data/demoDB.json` — демо-данные для показа прототипа;
- `data/TemDB.json` — пустой шаблон для рабочих данных организации;
- `data/refDB.json` — справочники платформы и содержимое «Базы знаний».

Рабочие данные пользователя хранятся в браузере (localStorage, ключ `bu.temdb`).
