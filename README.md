# Buhuchet.kg — кликабельный прототип

Прототип системы автоматизации бухгалтерского аутсорсинга: учёт сдачи налоговых отчётов по контрагентам, задачи, поступления и оплата налогов, справочники платформы.

- Файл прототипа: [`index.html`](index.html) — самодостаточная HTML-страница, открывается в браузере без сборки.
- Текущая версия: **v25** от 15.10.2026 — исправлены мелкие дефекты из проверки v22 и добавлено всё, что было в ТЗ, но отсутствовало в макете (кроме налогового каталога): изменение назначения отчёта и «Изменить срок» с причиной, «Перевод» со счёта организации сотруднику, «Закрыть месяц» в списаниях, платёжное поручение, правка и удаление счетов организации, логотип и часовой пояс, удаление пустого контрагента, Excel для календаря и кодов стран, копирование календаря на следующий год, вкладки «Категории задач», «Причины изменения срока», «Шаблоны ролей», все модули в нижней панели телефона, настройки списков на пользователя.

- Техническое задание: [`docs/ТЗ Buhuchet.kg.md`](docs/ТЗ%20Buhuchet.kg.md) (итоговое, 13.10.2026).
- Инструкция по системе: [`docs/Инструкция Buhuchet.kg.md`](docs/Инструкция%20Buhuchet.kg.md).

Каждая новая версия прототипа заменяет `index.html`, номер версии и дата обновляются здесь.
