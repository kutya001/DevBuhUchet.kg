# Buhuchet.kg — кликабельный прототип

Прототип системы автоматизации бухгалтерского аутсорсинга: учёт сдачи налоговых отчётов по контрагентам, задачи, поступления и оплата налогов, справочники платформы.

- Файл прототипа: [`index.html`](index.html) — самодостаточная HTML-страница, открывается в браузере без сборки.
- Текущая версия: **v12** от 14.10.2026 — модуль «Показатели контрагентов» (вкладки «Ввод за месяц», «За период», «Не заполнено», «Настройка показателей»); вкладка «Показатели» в карточке контрагента с итогами за период (сумма, среднее, максимум, минимум) и графиком по месяцам; статус месяца «Не заполнено → Заполнено → Проверено»; права «Настраивать показатели» и «Проверять показатели».

- Техническое задание: [`docs/ТЗ Buhuchet.kg.md`](docs/ТЗ%20Buhuchet.kg.md) (итоговое, 13.10.2026).
- Инструкция по системе: [`docs/Инструкция Buhuchet.kg.md`](docs/Инструкция%20Buhuchet.kg.md).

Каждая новая версия прототипа заменяет `index.html`, номер версии и дата обновляются здесь.
